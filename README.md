# cv2-event-collision-mod-ue4ss

A simple mod for **Code Vein II** that displays collision and event-related meshes in-game.

Game Version tested: v2.0.2.0.

## Installation

Extract the mod files to:

`C:\Program Files (x86)\Steam\steamapps\common\CodeVein2\CodeVein2\Binaries\Win64`

## Hotkeys

- **F2 — Red:** Possible invisible collision meshes.
- **F3 — Orange:** Cutscene/event triggers.
- **F4 — Other:** Entity capsules and interactable objects (**Not recommended:** this mode may cause frequent crashes).

## How to Disable the Mod

Rename:

`dwmapi.dll`

to any other filename.
