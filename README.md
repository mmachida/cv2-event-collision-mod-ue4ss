# cv2-event-collision-mod-ue4ss
cv2-event-collision-mod-ue4ss

Extract to:
- C:\Program Files (x86)\Steam\steamapps\common\CodeVein2\CodeVein2\Binaries\Win64

Hotkeys:
- F2 = Red - possible invisible collision meshes.
- F3 = Orange - cutscene triggers.
- F4 = Entity capsules and interactable objects.

How to disable the mod:
- Rename dwmapi.dll.
